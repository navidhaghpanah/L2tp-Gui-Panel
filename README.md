# L2TP VPN + Panel (Farsi)

نصب یک‌مرحله‌ای سرور **L2TP/IPsec** به‌همراه یک **پنل وب فارسی** برای مدیریت کاربران.

## امکانات
- افزودن/حذف کاربر از طریق پنل
- **سهمیه ترافیک** برای هر کاربر (گیگابایت)
- **محدودیت زمانی / انقضا** برای هر کاربر (روز)
- **تک‌نشست** (هر کاربر فقط یک اتصال هم‌زمان)
- **محدودیت پهنای‌باند** پیش‌فرض: دانلود ۲۰۰ / آپلود ۲۰ مگابیت
- قطع و بلاک خودکار هنگام اتمام حجم یا انقضا
- صفحه ورود اختصاصی + **SSL (Let's Encrypt)**
- تاریخ شمسی، رابط RTL

## نصب
```bash
sudo bash install.sh
```
هنگام نصب این موارد پرسیده می‌شود: دامنه، ایمیل SSL، نام‌کاربری/رمز پنل، PSK و اولین کاربر VPN.

> پیش‌نیاز: دامنه باید به IP سرور اشاره کند و پورت‌های **UDP 500/4500** و **TCP 80/443** در فایروال/Security Group باز باشند.

## اجزا
- `vpn-panel.py` — پنل وب (پورت داخلی 8088، پشت nginx)
- `vpn-enforce.py` — سرویس اعمال محدودیت حجم/زمان
- سرویس‌های systemd: `vpn-panel`, `vpn-enforce`

## مدیریت دستی
- کاربران: `/etc/ppp/chap-secrets`
- سهمیه/انقضا: `/var/lib/vpnstat/meta.json`
- مصرف: `/var/lib/vpnstat/usage.json`
